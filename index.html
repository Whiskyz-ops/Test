India ⇄ US

The Monitor is the product.

Two Layer 1 intake forms collect the India + US picture. A shared computation & conflict engine turns that into residency, FTC, limits, documents and per-jurisdiction exposure — all surfaced in one place: the Monitor. There is no separate dashboard.

THE APP

Monitor (Next.js)

Exposure map (India + US, drill into US states), KPI tiers, and — folded in — Conflicts, FTC reconciliation, tax computation, documents & limits. Individual and business (company) taxpayers. Sphere-inspired.

To run the demo: double-click start.command (Mac/Linux) or start.bat (Windows). It serves the router, both Layer 1 forms and the Monitor from one address — which is what makes the Layer 0 → Layer 1 → Layer 2 data flow work. Pick a test profile in the Monitor, then open a form: it's populated from that profile. 

./start.command        # or start.bat on Windows → http://localhost:8099/

# Dev mode is for editing the Monitor's React code only:
cd monitor-next && npm install && npm run dev   # :3000 — do NOT open the forms from a different address than this
